# RNA 3D 구현·검사 기록 (2026-10-23)

배포 대상: https://ahntibody87.github.io/advanced-life-science/gene-expression/rna-lab/

GitHub Pages 기존 홈페이지에 추가합니다. 계산 서버, 사용자 계정, DB는 만들지 않습니다. 기존 RibossFold와 미션 채점은 유지합니다. 자유 실험실에 RoseTTAFold3 / LocalFold int5 모델을 WebGPU Worker로 연결했습니다.

## 실제 브라우저 검사

- 16 nt `GGGCGAAAGCCCUUUU`: 원자 341개, 예측 약 35~42초(다운로드 제외). O3′–P 간격 검사 이상 0곳, 기하학적 염기쌍 후보 4쌍. 이 후보들은 빠른 2차 예측과 일치했습니다.
- 기본 12 nt 헤어핀: 예측 약 32초. 골격 간격 이상 8곳, 후보 0쌍. 모델의 신뢰도만으로 올바른 구조라 판단하면 안 되는 사례입니다. 화면에 골격 이상 안내를 표시합니다.
- 120 nt 반복 서열: 예측 약 90초. 골격 간격 이상 81곳, 후보 0쌍. 계산은 완료되지만 구조 품질이 낮았습니다. 길이 상한은 계산 입력의 상한이며 정확성 보장이 아닙니다.
- Boltz-2 대체 모델은 모델 다운로드 단계에서 실패하여 배포 구성에서 제외했습니다.
- 결과 JSON 저장·같은 서열로 불러오기, 적용 전 서열 수정 시 결과 숨김과 예측 버튼 비활성화, 계산 중단, 미션방 전환 시 3D 숨김을 확인했습니다.
- 검사 환경은 Codex 내장 브라우저의 WebGPU입니다. 실제 학생 노트북·iPad·Android 패드에서의 속도·메모리 검사는 수행하지 않았습니다.

## 자동 검사

사이트 생성·328개 내부 경로 검사, 기존 RNA 분자 표시·미션 채점·가위 모형 검사를 수행합니다. 새 검사는 잘못된 구조 표기와 서열 불일치 파일을 거부하고, 포개진 염기를 염기쌍으로 잘못 표시하지 않는지 및 101개 브라우저 모듈의 import 경로를 확인합니다.

## 해석상의 제한

현재 모델을 임의 RNA 서열에 대한 검증된 정답 생성기로 취급할 수 없습니다. 특히 골격 이상 결과는 올바른 RNA 구조로 해석하면 안 됩니다. 이 기능은 **실험적 예측과 예측 간 차이를 관찰하는 기능**입니다. 골격 거리 검사 통과 또한 전체 구조의 정확성·화학적 타당성을 보장하지 않습니다. 염기쌍은 FR3D/DSSR 정밀 주석 대신 명시한 거리·평면 기준의 후보로 표시합니다. 여러 비정형 상호작용은 누락할 수 있습니다.
