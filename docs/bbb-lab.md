# BBB 약물 설계 실험실

경로: `/advanced-life-science/regulation-defense/bbb-lab/`.
브라우저에서만 실행되는 정적 교육 자료. 계정, 외부 API, 학생 정보 수집 없음.

## 과학적 범위

- 혈관 내강 → 연속된 내피세포층 → 기저막 → 뇌 간질의 단면을 표현한다. 치밀결합은 이웃 내피세포 사이에 있으며 주위세포·성상세포 발끝은 혈관 바깥에서 기능을 지지한다. 적혈구·혈장 단백질은 혈관 내강에 표시한다.
- 약물의 수동확산과 전구약물의 전달·활성화만 조작한다. P-gp 조절, 항체 셔틀, 장벽 개방 등은 포함하지 않는다.
- logP는 중성 분자의 지용성, MW는 질량, TPSA는 극성 표면적, HBD는 수소결합 공여체 수. 구조에서 계산한 값이 아닌 가상 독립 변수다. MW와 TPSA에 절대적인 통과 문턱을 두지 않는다.
- pKa는 단일 이온화 부위에 대한 Henderson–Hasselbalch 평형으로 계산한다. 산형의 중성 비율은 `1/(1+10^(pH-pKa))`, 염기형은 `1/(1+10^(pKa-pH))`. 염기형은 BH+의 pKa다. pH 범위 6~9는 탐구용이며 정상 혈액의 범위를 뜻하지 않는다. 양쪽 구획의 pH는 같다고 가정한다. 다중 이온화·쌍극이온·pH 포획은 다루지 않는다.

## 모델

`assets/activities/bbb-lab/model.mjs`에 순수 계산을 분리했다. 상태는 혈액/내피세포/뇌 각각의 활성 약물·전구약물과 제거된 양의 7개다. 초기량은 100이며 실제 투여량 단위가 아니다. 세 구획은 유효 크기가 같다고 가정한다. 양방향 확산은 양의 차이에 비례하며, 실제 부피·농도·막 면적을 보정한 PBPK 모델이 아니다.

수동이동 속도 계수는 다음 가정식의 곱이다.

```
size = exp(-max(0, MW-180)/440)
polar = exp(-TPSA/110)
hydrogen = exp(-0.22*HBD)
membrane = 1/(1+exp(-(logP-0.8)*1.5))
availability = 1/(1+0.18*10^max(0,logP-2))
rate = 0.9*size*polar*hydrogen*membrane*availability*(neutral+0.015*(1-neutral))
```

이온형의 제한적인 잔여 투과를 두고, 높은 지용성에서는 수중 이용 가능성이 감소한다는 경향을 표현한다. 약동학 데이터에 적합한 식이 아니며 CNS MPO 점수나 실제 BBB 예측 모델로 표시하지 않는다. 혈액→내피 확산량은 `rate*(혈액량-내피량)`, 내피→뇌는 `0.8*rate*(내피량-뇌량)`. 음수일 때 반대 방향으로 이동한다. 활성 약물과 전구약물에 각각 적용한다.

### 전구약물

위 슬라이더는 원래 약물의 물성이다. 전구약물의 변화량을 화면에 따로 표시한다. 실제 화학 반응을 계산하지 않는다.

- 극성 가림형: logP +0.8(상한 7), MW +42, TPSA −35(하한 10), HBD −1(하한 0). pKa는 유지한다. 특정 작용기를 정확하게 변환한 결과가 아닌 교육용 설계 카드다.
- 아미노산 운반체형: logP −0.4, MW +100, TPSA +25, HBD +1, pKa 유지. 특정 구조를 인식하는 LAT1 활용 연구에서 영감을 얻었으며 사용자 화면에서는 ‘아미노산 운반체’로 설명한다. 실제로 기질이 되는 특정 전구약물이라는 전제다. 추가 혈액→내피 유입은 `1.1*혈액전구약물/(25+혈액전구약물)`, 내피→뇌 방출은 `0.18*내피전구약물`. 양쪽 막 수송·다른 운반 경로·교환 기질 등을 묶은 가상 유효 전달식이며 LAT1이 관통 구멍처럼 양쪽 막을 잇는다는 의미가 아니다. 그림에서는 독립된 막 단백질로 표시한다.
- 혈액에서의 활성화 계수: 높은 안정성 0.003, 중간 0.035, 낮은 안정성 0.16.
- 뇌에서의 활성화 계수: 느림 0.008, 중간 0.12, 빠름 0.4. 활성화 시 같은 구획에서 전구약물량이 활성 약물량으로 1:1 전환된다. 단위는 분자 질량이 아닌 부모 약물 등가량이다.
- 제거: 혈액 구획 0.006, 뇌 구획 0.004. 제거량은 별도 구획으로 보존한다. 내피 내 활성화는 제외한다.

0~60의 무차원 관찰 단계를 dt=0.025로 계산하고 0.5마다 표본화한다. 원래 약물 투여군과 전구약물 투여군의 초기 활성 성분 등가량은 동일하다. 실제 임상 용량·시간·확률로 해석하지 않는다. 계산은 결정론적이며 단면의 점은 구획별 양의 표본 표시다. 구조·속도·분자 크기·그림의 개수는 실제 축척이 아니다. 운반체 표시는 경로 개념도이며 픽셀 위치로 수송 기작을 계산하지 않는다.

결과는 현재 뇌 구획의 활성 약물/미활성 전구약물 잔존량을 초기량 대비 %로 제시한다. 누적 통과량이나 임상 도달률과 구분한다. 기록은 메모리에만 보관하며 페이지 이동 시 사라진다.
