## 시나리오 JSON

`schemaVersion: 1` 형식이며 HTML의 `data-scenario`가 JSON 파일을 선택한다.

| 필드 | 의미 |
|---|---|
| `id`, `title`, `brief`, `virus`, `genome`, `target`, `productBp` | 상황과 표적 설명, 학습용 산물 크기 |
| `samples` | A·B·positive·negative 네 역할의 `id`, 표시 이름 `label`, 시료 `material`, 표적 유무 `positive`, 대조군 여부 `control` |
| `samples[].bandsBp` | 선택 필드. 별도 밴드 크기 배열을 제공하면 해당 레인의 결과에 사용 |
| `reagents` | 넣는 순서대로 된 시약 배열. `id`, `label`, `missingRule`, 선택적 `enzyme` |
| `program.defaults` | 역전사 사용 여부, 각 온도, 사이클 수 |
| `program.limits` | 각 설정의 학습용 최솟값·최댓값과 경고 ID. 실제 실험의 보편적 한계가 아님 |
| `steps` | 각 단계 제목·권장 기기·체크리스트·접힌 ‘왜?’ 설명 |
| `warnings` | 규칙 ID → `cause`(원인), `molecule`(분자 변화), `consequence`(판정 영향·복구 안내) |
| `markerBp`, `answer`, `modelInterpretation`, `sources` | 마커, 감염자 선택 정답, 모범 해석 문단, 과학 출처 |

같은 RT-PCR 흐름의 다른 상황은 JSON을 복사하고 위 필드를 바꾼 뒤 활동 HTML의 `data-scenario` 경로를 바꾼다. 시료 역할 ID A·B·positive·negative는 유지하고 표시 이름·정답·재료를 변경한다. 경고 ID는 모델에서 참조하므로 유지한다. 새 경고 조건은 `model.mjs`의 `issues()`와 검사를 함께 추가한다.

친자 확인처럼 여러 유전자좌를 비교하거나, DNA 기반 GMO 검출처럼 역전사를 생략하는 활동은 JSON 추가와 함께 해당 실험 흐름·분자 뷰를 확장해야 한다. 현 버전은 요청한 RNA 바이러스 RT-PCR을 정확하게 표현하는 엔진이다. 단순히 제목만 바꾸어 다른 검사로 사용하지 않는다.

## 로컬 실행

저장소 루트에서 Node.js로 실행한다. 추가 패키지는 필요 없다.

```text
node scripts/build.mjs
node scripts/check.mjs
node scripts/check-amplicon.mjs
node scripts/check-course-access.mjs
```

정적 HTTP 서버로 저장소 루트를 제공한다. Python이 설치되어 있으면 다음과 같이 실행할 수 있다.

```text
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/advanced-life-science/biotechnology/amplicon/`을 열고 기존 과목 비밀번호로 입장한다. `file://`로 직접 열면 JSON·모듈을 읽지 못하므로 HTTP 서버가 필요하다. 빌드는 기존 날짜 자동 갱신 규칙에 따라 홈 하단 날짜도 갱신한다.

## 정상 진행 체크리스트

- [ ] 04 카드에 1개 활동이 표시되고 AMPLICON 카드가 열린다. 미입장 상태에서는 기존 비밀번호 화면이 먼저 나온다.
- [ ] 웹 구현 실험실에서 WASD·방향키 이동, E 상호작용, 바닥 클릭/탭 이동, 기기 클릭/탭, 터치 방향 패드가 작동한다. 바로 이동 버튼도 사용 가능하다.
- [ ] 아이스박스의 뚜껑을 열고 A·B·양성 대조군·음성 대조군용 증류수가 꽂힌 냉각 랙을 꺼낸다. ‘랙을 들고 작업대로’를 누르면 캐릭터가 냉각 랙을 든다. 직접 작업대까지 이동한 뒤 작업대를 연다.
- [ ] 팁 박스 → 시약병 → 반응 튜브 → 폐기통을 차례로 누른다. 팁을 끼운 상태에서 병을 반응 튜브로 끌어도 흡입과 분주가 이어진다.
- [ ] 화살표로 표시된 A 반응관에 버퍼·dNTP → 스파이크 유전자 프라이머 → 역전사 효소 → Taq → A 추출 RNA 순으로 넣는다. 효소병은 작업대의 얼음 위에 놓여 있다. 마지막 팁을 버리면 작업대 그림 안에 “나머지 반응관에 자동으로 넣을까요?”가 뜬다. “네.”를 누르면 나머지 반응관에 공통 시약과 해당 원본 시료가 자동으로 분주된다.
- [ ] 표준 품질에서 손이 팁 박스→용액→튜브→폐기통으로 이동한다. 각 튜브를 눌러 성분을 확인한다.
- [ ] 볼텍스 접촉판에 반응관을 한 개씩 올려 약 1.5초간 눌러 혼합한 뒤 다음 단계를 누르면 캐릭터가 반응관을 든다. 캐릭터를 직접 움직여 원심분리기로 이동한다. 네 관을 원심분리기의 로터 위로 끌어 놓거나 구멍을 눌러 장착한 뒤 “덮개 닫고 스핀다운”을 누른다.
- [ ] 네 튜브를 PCR 기기에 한 번에 넣고 기본 프로그램으로 가동한다. 왼쪽 기기에 온도와 사이클, 오른쪽에 온도·증폭량 그래프가 표시된다. 아래쪽에서는 약 30초 동안 두 튜브의 분자 관찰이 재생된다. 일시정지·계속·건너뛰기가 작동한다.
- [ ] 스파이크 유전자가 있는 튜브에는 역전사·DNA 증폭이 보이고, 없는 튜브에는 프라이머만 떠다닌다. 모든 가닥 방향과 합성 방향을 확인한다.
- [ ] 레인 1~5에는 DNA 크기 마커, A, B, 양성 대조군, 음성 대조군를 순서대로 넣는다. 병을 누른 뒤 해당 웰을 누르거나 병에서 웰로 끌어 로딩한다.
- [ ] 검정 − 선이 웰 쪽, 빨강 + 선이 반대쪽에 연결되었는지 확인하고 전원을 켠다. 장치 그림 안에서 추적 색소의 이동과 완료 표시를 확인한다. 밴드는 UV 관찰에서 확인한다.
- [ ] 다음 단계를 누르면 캐릭터가 겔을 든다. 캐릭터를 직접 움직여 UV 관찰기로 이동한다. 겔을 받침 위에 놓고 보호 덮개를 닫는다. UV에서 A와 양성 대조군만 약 300bp 밴드가 보인다. A 선택·근거 작성·제출 후 내 글과 모범 해석이 나란히 나온다.
- [ ] 새로고침하면 브리핑부터 시작하고 답안이 남지 않는다.
- [ ] 1366×768 크롬북/노트북, 768×1024 태블릿에서 잘림 없이 진행한다. 저사양 옵션도 확인한다.

## 오조작 직접 확인

피펫팅 중 잘못된 조작을 하면 빨간 ✕와 다음 행동이 즉시 표시된다. ‘다음 단계’를 누를 때는 단계 버튼 아래에 다음에 할 일을 한 문장으로 표시한다. ‘다음 단계’ 또는 기기 가동 시 미완료 상태를 알리는 경고창은 ① 원인 → ② 분자 수준 → ③ 판정 영향 순서이며 ‘돌아가서 수정하기’ 버튼만 있다. 수정 전에는 단계가 넘어가지 않는다.

| 재현 | 복구 |
|---|---|
| 폐기통을 거치지 않고 사용한 팁으로 다음 용액/시료 분주 | 폐기통에서 사용한 팁을 버리고 새 팁 장착 |
| 버퍼·dNTP, 프라이머, 역전사 효소, Taq을 각각 빼고 조제 | 화면이 안내하는 다음 성분부터 순서대로 분주 |
| 시료 누락·중복·다른 시료 선택 | 화면에 표시된 순서와 반응관 확인 |
| 시료부터 먼저 넣기 | 해당 튜브 새로 조제 |
| 대조군을 받기 전에 다음 단계 | 아이스박스로 돌아가 수령 |
| 혼합 후 스핀다운 없이 다음 단계 | 미니 원심분리기에서 스핀다운 |
| PCR 튜브를 일부만 넣기 | 네 튜브 선택 |
| 마커 미로딩·지정된 웰과 다른 시료 선택 | 웰 번호와 지정 시료를 확인하고 해당 위치에 로딩 |
| 웰 쪽 + 극 | 웰 쪽 − 극으로 수정 |

입장 보호는 기존 정적 사이트의 화면 입장 제한이며, 이 활동이 별도의 보안 방식이나 학생 데이터 수집을 추가하지 않는다.

## 과학 모형의 범위

실제 반응 시간·효율·분자 수를 재현하는 계산 모델이 아니라, 정상 반응의 방향성과 단계 관계를 보여 주는 개념 모형이다. 기본 재생은 약 57초, 이론적 증폭량은 2ⁿ으로 표시한다. RNA에서 cDNA를 만든 뒤 DNA를 증폭하며 새 가닥 합성은 프라이머 3′ 말단에서 항상 5′→3′로 진행된다. 초기 긴 산물과 정해진 길이 산물의 구분은 3번째 사이클 안내로 제시한다.

이 활동의 300bp 크기와 온도 허용 범위는 학습용이다. 실제 B 시료의 채취·추출 적절성을 검증하는 내부 대조군을 생략했음을 모범 해석에서 명시한다. 실제 진단의 실시간 RT-PCR과 전기영동 교육 활동도 구분한다.

출처: [NEB RT-PCR](https://www.neb-online.de/en/pcr-and-dna-amplification/reverse-transcription-cdna-synthesis/onetaq-one-step/), [NIST 프라이머 정의](https://www.nist.gov/glossary-term/29811).

카드 삽화는 기본 이미지 생성 도구로 만들고 `assets/biology-art-v1/tool-amplicon.webp`에 저장했다. 그림 프롬프트는 옅은 회청색 배경의 16:9 과학 교재 수채화, 왼쪽의 열린 써멀 사이클러와 반응 튜브, 오른쪽의 전기영동 겔과 크기 마커를 지정했다. 예시 밴드는 시료 식별자 없이 그렸다.
