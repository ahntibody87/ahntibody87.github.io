# RNA 3차 구조 개선 (2026-10-28)

대상 저장소: https://github.com/ahntibody87/ahntibody87.github.io

공개 주소: https://ahntibody87.github.io/advanced-life-science/gene-expression/rna-lab/

## 실행과 표시

기존 RoseTTAFold3 / LocalFold int5 모델과 WebGPU 실행을 유지합니다. 새 서버, DB, API 키는 없습니다. 같은 모델 가중치를 한 번 내려받아 사용합니다. 모델의 수치 커널과 가중치는 변경하지 않습니다.

seed 0·1·2로 200단계 확산 후보를 세 개 생성합니다. 재순환 설정은 1입니다. 두 번째부터는 동일한 서열의 trunk와 target features를 재사용하고 확산의 난수 조건을 바꿉니다. 후보들은 완전히 독립적인 모델 예측이 아닙니다. 2차 구조를 제약하거나 2차 결과와 일치하는 후보를 우선하지 않습니다. 전체 진행률·개별 후보 검사 결과·중단 버튼을 제공합니다.

거리 기반 결합선 추정을 제거했습니다. 3Dmol의 `addAtoms`에 명시적인 결합 목록을 전달합니다. RNA 표준 A/C/G/U의 결합은 wwPDB Chemical Component Dictionary에서 가져오고, 이웃 뉴클레오타이드의 O3′–P 공유결합을 추가합니다. 입력 PDB의 CONECT나 원자 근접성으로 결합을 추가하지 않습니다. 결합 차수의 차이를 생략한 단일 막대 표시이며 수소 결합을 공유결합 막대로 그리지 않습니다. 심하게 비정상적인 길이의 결합은 생략하고, 원자는 남겨 이상이 드러나게 합니다.

기본 색상은 당(청회색), 인산(주황), 염기(A/U/G/C별 별도 색)입니다. 연결 산소 O3′·O5′는 표시상의 일관성을 위해 당 색으로 묶습니다. 골격은 굵게, 염기는 가늘게 표시합니다. 골격만 보기, 보정 전 pLDDT 색상, 5′/3′ 및 선택 뉴클레오타이드 표지를 제공합니다. 성분·표시 전환에서 카메라를 유지합니다. 모바일에서 3D 화면을 보는 동안 기존 2D 염기 편집 막대가 화면을 가리지 않도록 숨깁니다.

## 화학 정의와 검사

- 정의: https://www.wwpdb.org/data/ccd
- 내려받은 원본: https://files.rcsb.org/ligands/download/A.cif (C/G/U도 동일 형식)
- `rna-chemistry.js`에 원본 SHA-256, 중원자 이름·원소·기준 좌표·공유결합 목록을 포함합니다.
- 재생성: `node scripts/generate-rna-chemistry.mjs <A/C/G/U.cif가 있는 폴더>`
- 검사 프로그램: `node scripts/check-rna-quality.mjs`

원자가 누락되었는지, 골격·당 고리·당–염기 연결·염기 고리·인산 결합의 길이, 잔기 내부 결합각, 당의 네 입체중심 방향, 염기 평면, 비공유 원자 충돌을 검사합니다. 공유결합으로 1단계/2단계 떨어진 원자쌍은 비공유 충돌에서 제외합니다. 실제 5′ 말단에 인산이 없는 경우는 허용합니다.

이 검사는 **앱의 보수적인 선별 규칙**이며 MolProbity/wwPDB 정밀 검증이나 실제 접힘의 정확도 평가가 아닙니다. CCD의 이상 좌표에서 얻은 길이·각도는 선별 기준이지, 측정 오차 분포나 통계적인 Z-score가 아닙니다.

- 결합 길이: 기준에서 0.25 Å 이상 벗어나면 이상으로 집계합니다. 0.6 Å 초과 편차, 0.75 Å 미만 거리, 2.5 Å 초과 거리는 심한 이상입니다.
- 결합각: 30° 초과 편차를 집계하고 55° 초과를 심한 이상으로 분류합니다.
- 염기 평면: 기준 평면에서 0.2 Å 초과 이탈을 집계하고 0.5 Å 초과는 심한 이상으로 분류합니다.
- 충돌: C/N/O/P의 반데르발스 반지름 합보다 0.65 Å 넘게 가까운 쌍을 집계하고 1.0 Å 초과 겹침은 심한 충돌로 분류합니다. 수소를 더하는 MolProbity clashscore가 아닙니다.
- 누락/지원하지 않는 원자, 심한 결합·각도·평면·충돌 이상, 당의 입체배치 이상이 있는 후보는 제외합니다. 보통 결합 이상 수는 전체 결합의 3%(최소 허용 수 2개), 작은 충돌은 중원자 수의 3%(최소 허용 수 3쌍)까지 허용합니다. 초기 검사에서 뉴클레오타이드 수로 작은 접촉 수를 제한하면 실험 구조도 과도하게 거부할 수 있어 중원자 수로 정규화했습니다. 이 수치는 앱의 선별 정책이며 검증된 정확도 경계가 아닙니다.
- 통과 후보 중 구조 이상 점수가 낮은 후보를 선택하고, 같은 점수에서는 원 모델의 평균 pLDDT를 참고합니다. 가장 높은 pLDDT가 다른 구조 이상을 상쇄할 수 없습니다.

## 가벼운 보정과 원본 보존

공유결합 길이, 이웃 결합의 1–3 거리, 충돌 감소, 원래 위치로의 억제를 함께 사용한 제한된 기하 최적화입니다. 한 원자를 최대 0.3 Å 움직이며 저장 좌표의 반올림 오차를 포함하면 약 0.301 Å까지입니다. 최대 80회이고 목표 함수가 감소할 때만 다음 단계를 수용합니다. 심한 이상이 있는 입력은 보정하지 않습니다. 구조 이상 점수·결합 RMS 오차·충돌 수가 악화되지 않을 때만 보정을 채택합니다.

이는 **분자동역학이나 Amber 에너지 최소화가 아닙니다.** 잘못된 전체 접힘, 끊어진 사슬, 뒤집힌 당, 심하게 겹친 구조를 정상처럼 복구하지 않습니다. pLDDT는 보정 전 모델의 값이며 새 신뢰도로 재해석하지 않습니다.

저장 JSON 형식 `rna-lab-3d-v1`은 유지하며 보정 전 `rawPdb`, 보정 후 `pdb`, 후보별 검사, 선택 seed, 검사 버전, 보정 이동량을 추가했습니다. PDB 다운로드에는 보정 여부와 신뢰도가 보정 전 값이라는 REMARK를 넣습니다. 예전 JSON도 새 기준으로 검사하여 경고와 함께 참고용으로 표시합니다. 예전 캐시는 자동 결과로 재사용하지 않습니다. 세 후보가 모두 미통과하면 새 3D 결과와 저장 버튼을 활성화하지 않습니다.

## 검증

공개 NMR 헤어핀 [PDB 1UUU](https://www.rcsb.org/structure/1UUU), 첫 모델의 중원자 399개를 검사 기준 자료로 사용합니다. 이 자료는 예측 성공 사례가 아닌 **실험 구조를 사용한 검사·보정·표시 검증 자료**입니다. 작은 충돌 8쌍에서 1쌍, 결합 길이 RMS 오차 0.0340 Å에서 0.0208 Å로 감소했고 최대 이동은 0.0492 Å입니다. 골격·당 입체배치는 유지됐습니다.

회귀 검사는 정상 골격과 공유결합 목록, 골격 단절·당 고리·당–염기·염기 고리 손상·원자 누락·충돌의 검출, 심한 입력 보정 거부, 0.301 Å 이동 한도, 원본 불변, 원본 신뢰도 보존, PDB 왕복, 후보 선택을 확인합니다. 실제 Chrome/3Dmol에서 성분 표시·골격만 보기·카메라 유지·2D 선택 연동·원본 포함 저장·예전 비정상 결과 경고·모바일 가로 넘침을 확인합니다.

로컬 Chrome WebGPU에서 실제 엔진으로 다음 세 서열을 실행했습니다. 가중치는 고정 revision의 SHA-256을 확인한 원본 그대로이며, 반복 검사에서는 동일 파일의 로컬 테스트 캐시를 사용했습니다. 아래 계산 시간은 다운로드를 제외한 해당 실행 환경의 기록입니다.

| 입력 | 결과 |
|---|---|
| `GGGCGAAAGCCCUUUU` (16 nt) | 세 후보 모두 기본 검사 통과. 작은 충돌 7/9/10쌍인 후보 중 seed 0 선택. 총 약 88초. 선택 후보는 보정 전 작은 충돌 16쌍→7쌍, 결합 길이 RMS 0.0518→0.0283 Å, 최대 이동 0.0928 Å. 원래 염기쌍 후보 네 쌍을 그대로 유지. |
| `GGGGAAAACCCC` (12 nt) | 세 후보 모두 미통과. 골격 이상 9/8/11곳, 심한 충돌 1224/1405/1078쌍. 큰 손상이므로 기하 보정은 적용하지 않았고 3D·결과 저장을 활성화하지 않음. 총 약 88초. |
| 두 헤어핀 프리셋을 반복하여 만든 60 nt 시험 서열 | 세 후보 모두 미통과. 골격 이상 49/52/48곳, 심한 충돌 5889/6895/8087쌍. 기하 보정과 기본 3D 표시 거부. 사용자 첨부 이미지의 정확한 서열을 검사한 것은 아님. |

세 실행 모두 브라우저의 JavaScript 예외는 없었습니다. 16 nt 실행으로 실제 Worker의 후보 전달·선택·보정 좌표 표시·검사 기록 및 원본 포함 IndexedDB 저장을 확인했고, 12/60 nt 실행으로 전체 후보 거부 처리를 확인했습니다. 전체 홈페이지의 15개 URL·455개 내부 링크와 기존 RNA 분자 표시·미션 채점·가위·3D 비교 회귀 검사를 통과했습니다.

**실질적 한계:** 이번 변경은 잘못된 결합선 표시를 제거하고, 작은 기하 이상을 개선하며, 심한 실패 결과를 걸러내는 개선입니다. 현재 모델이 임의 RNA를 올바르게 접도록 바뀐 것은 아닙니다. 특히 12 nt 및 시험한 60 nt에서는 유효한 후보를 얻지 못했습니다. 학생 기기 전체의 성능·정확성을 보장하지 않습니다.
