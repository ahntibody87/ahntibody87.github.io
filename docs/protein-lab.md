## 구조 비교 화면 개선 — 2026-10-28

- 비교 뷰어를 밝은 배경과 얇은 파랑(A)·주황(B) 리본으로 바꾸었습니다. 겹쳐 보기, 카메라가 함께 움직이는 나란히 보기, 방향·확대율을 유지하는 A/B 번갈아 보기를 제공합니다. 좁은 모바일 화면에서는 두 구조를 위아래로 배치합니다.
- 서열을 10개 위치 단위의 A/B 두 행으로 정렬하고, 치환 위치에 분홍 밑줄을 붙였습니다. 선택한 위치는 두 구조·두 서열·거리 그래프에서 연결되며, 다음 치환 위치/차이가 가장 큰 위치/선택 위치 확대/전체 보기를 제공합니다.
- 거리 그래프에 위치와 Å 눈금을 넣었습니다. 보라색 막대는 대응 Cα 거리, 아래 분홍 점은 치환 여부입니다. 눈금 고정은 다음 비교에도 유지되며 상한을 넘는 값은 별도로 표시하고 정확한 수치를 제공합니다. 0인 거리도 열 전체를 눌러 선택할 수 있습니다.
- 비교 화면은 `comparison-view.js`에서 관리합니다. 예측 엔진, 전체 위치 대응, RMSD와 TM-score 계산, CSV 수치는 변경하지 않았습니다. 보기 전환 시 다시 구조 정렬을 계산하지 않습니다. 입력이나 사슬을 바꾸면 기존 선택을 해제합니다.

## 기능

1. 아미노산 20종의 한글/영문 이름, 3레터/1레터 코드, L형 비이온형 전체 구조식(모든 탄소·수소 원자 명시), 회전 가능한 전체 분자 3D, 곁사슬·전하 설명. 3D는 PubChem의 중성 자유 아미노산 계산 좌표를 로컬에 포함하며 별도 계정이나 실시간 API가 필요 없습니다. 글리신은 비키랄입니다. pH 약 7에서의 곁사슬 분류이며 히스티딘의 부분 양전하를 따로 설명합니다.
2. 10–256 aa 단일 사슬 및 단일 FASTA 입력, 맨 위 기본 선택인 ‘직접 입력’과 예제 3종, 위치/범위의 20종 아미노산 치환(기본 프롤린), 되돌리기, 위치 선택, 실제 WebGPU 예측, 3Dmol 리본·곁사슬·색상, PDB 다운로드와 불러오기, 비교 A/B로 전달. 입력을 수정하면 이전 예측을 현재 결과로 저장하지 못하도록 표시·차단합니다.
3. 길이가 같은 야생형·치환 변이를 전체 위치별로 대응시켜 Cα 좌표를 비교합니다. RMSD 최소 제곱 겹침은 Horn quaternion 해법, TM-score는 동일 잔기 대응에서 여러 초기값과 반복 가중 최소 제곱으로 근사 최대화합니다. TM-score와 RMSD는 별도 최적화이며, 뷰어/거리 그래프는 RMSD 기준입니다. RCSB/TM-align 결과와 동일하다고 주장하지 않습니다. 사슬 선택, 두 구조 표시 전환, 위치별 거리 그래프, CSV 다운로드를 제공합니다.

## 예측 모델과 제한

- **Biohub ESMFold2 Experimental Fast base300M-step1500k**와 해당 ESM-C 300M/입력 shim. ESMFold v1이나 전체 크기의 ESMFold2 6B와 다른 경량 실험형 모델입니다. 사용자에게 모델명과 차이를 표시합니다.
- LocalFold WebGPU 구현 중 필요한 67개 모듈만 포함했습니다. 정확한 원본 revision과 파일 목록은 `vendor/localfold/PROVENANCE.json`에 있습니다. 모델 레지스트리만 필요한 두 번들로 제한했습니다.
- 신뢰도는 Synthyra의 별도 head이며 pLDDT는 0–100으로 환산합니다. distogram certainty를 pLDDT로 표시하지 않습니다. pTM과 두 구조 비교의 TM-score도 구분합니다.
- 첫 예측에서 약 270 MB(현재 257 MiB 정도)를 Hugging Face의 고정 revision에서 내려받습니다. 각 shard는 manifest의 SHA-256으로 검증하고 Cache Storage에 보관합니다. 이후 그래픽 계산은 기기 내부에서 수행합니다. 브라우저가 캐시를 정리하거나 캐시가 허용되지 않으면 파일을 다시 내려받습니다.
- ESM Atlas나 ColabFold MSA API를 사용하지 않으며, 입력 서열을 외부 예측 서버로 보내지 않습니다. 계정/API 키/DB/서버 환경변수가 필요 없습니다.
- Worker에서 실행하고, 중단 시 Worker를 종료합니다. 그래픽 장치가 끊기거나 메모리 예산을 초과하면 실패를 보고하며 가짜/대체 구조를 표시하지 않습니다. 그래픽 메모리 예산은 1.4 GiB로 제한합니다.
- WebGPU를 제공하지 않는 브라우저에서도 아미노산 학습과 PDB 관찰·비교는 가능합니다. 모든 학생 기기에서 같은 속도로 실행된다고 보장하지 않습니다. OS 보안 기능이나 관리 정책을 우회하지 않습니다.
- 구조는 정적 예측입니다. 접힘 경로, 변성 온도, 안정성, 약효 및 기능 상실을 계산하지 않습니다.

## 구조·서열 연결과 일반 아미노산 치환 — 2026-10-16

- 접힘 결과와 구조 비교에 `residue-inspector.js`를 사용합니다. 구조 또는 서열의 hover는 일시 강조, 클릭·터치는 선택 유지, 같은 잔기를 다시 누르기·‘선택 해제’·Esc는 해제입니다. 키보드로 서열 버튼에 초점을 맞춰 관찰하고 Enter/Space로 선택할 수도 있습니다. 정보 영역은 캔버스 밖에 두며 회전·확대를 가로채는 오버레이를 만들지 않습니다.
- 정보는 한글 이름, 3레터/1레터 코드, 사슬 내 관찰 서열 위치, 사슬, 실제 PDB 잔기 ID를 구분합니다. `chain + resi + insertion code`를 잔기 식별자로 사용합니다. 예를 들어 첫 잔기가 PDB 42라면 서열 위치는 1이며, 42와 42A 또는 다른 사슬의 42는 서로 다릅니다. PDB를 불러오면 기존과 같이 첫 모델에서 Cα가 있는 잔기의 순서로 사슬별 관찰 서열을 구성합니다. PDB에 없는 잔기를 복원하거나 전체 생물학적 서열의 위치를 추정하지 않습니다.
- 접힘 입력의 위치 선택은 현재 입력이 표시 중인 결과 서열과 같을 때만 구조에 연결됩니다. 이전 결과의 관찰 서열은 구조 아래에 남아 있으므로 편집한 서열과 혼동하지 않습니다. 입력 서열 아래의 다중 선택은 치환 대상이며 ‘치환 위치 해제’로 함께 지울 수 있습니다.
- pLDDT는 현재 예측 엔진이 반환한 잔기별 배열에서만 읽습니다. 일반 업로드 PDB의 B-factor는 pLDDT로 간주하지 않고 ‘pLDDT 정보 없음’으로 표시합니다. 평균·잔기별 신뢰도 계산과 모델은 변경하지 않았습니다.
- 비교에서는 선택한 A/B 사슬의 기존 위치 고정 대응을 사용하고 양쪽 잔기와 서열 위치를 함께 강조합니다. 선택한 두 Cα 사이 거리는 기존 `compareResidues().distances`로 표시하므로 화면·거리 그래프·CSV와 같은 RMSD 최소 제곱 겹침 기준입니다. TM-score 최적화 겹침을 사용하지 않습니다. 사슬 또는 입력 구조를 바꾸면 관찰 선택도 무효화합니다.
- 치환 목록은 20종 모두 ‘한글 이름 · 3레터 / 1레터’를 표시합니다. `8, 12-14` 범위 또는 입력 서열 버튼으로 선택한 여러 위치를 치환할 수 있습니다. 직접 입력에도 치환 전 서열을 기준으로 변경 위치를 표시하며, 되돌리기 이력에는 표시 기준도 보존합니다. 이전 결과의 비교 전송 차단은 버튼과 이벤트 처리 양쪽에서 검사합니다.
- 검사 확장: 20종 치환, 중복 범위, PDB 번호 차이·삽입 코드·사슬 중복, 명시적 pLDDT 0과 누락값, 업로드 B-factor를 신뢰도로 오인하지 않는지 검사합니다. 기존 회전·RMSD·TM-score 검사는 유지합니다.
- 실제 Chrome 검사: 3D 리본의 마우스 hover/클릭, 선택 유지·해제, 색상 변경, 회전 드래그, 42/42A 및 A/B 사슬 구분, 입력과 구조의 양방향 강조, 범위 치환·되돌리기·초기화·변경 표시·이전 결과 전송 차단, A/B 대응 거리와 그래프 일치, 사슬 변경 무효화, 모바일 서열 및 3D 리본 터치 선택, 390 px 가로 넘침 없음, 페이지 오류 없음. 기존 모델의 새 HP35 예측도 완료했고 평균 pLDDT 81.0 및 8번 잔기 pLDDT 88.2 표시를 확인했습니다.
