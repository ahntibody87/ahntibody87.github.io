## 학습 흐름

1. 수업 재현실: 7주차 PPT 6~10쪽의 두 입력 가중, 억제 시점, 연결 강도와 시간 선택성을 조작한다. A만/B만/함께 대조군을 겹쳐 본다.
2. 실제 뉴런 비교실: Allen의 생쥐 시각피질 뇌 절편 세포 2개, 자극 10조건의 전류·막전위를 비교한다. 보정용 조건에서 조절한 모델을 고정하고 검증 조건으로 이동한다. 시험용 자료를 보면서 조절하면 독립 검증이 되지 않음을 표시한다. 전체 파형의 유사도 점수는 제공하지 않는다.
3. 자유 탐구실: 뉴런 2~12개·연결 48개까지 회로를 설계하고 17×11 조건을 비교한다. 입력 시점의 정규분포 흔들림을 켜면 조건당 20회 실행한다. 청각 모티프는 11방향×20회에서 정확도/무반응/양쪽 오반응/반대쪽 반응을 나눈다.

탐구 노트에는 조건·수치·그래프를 묶어 최대 24개 결과를 기기 저장소에 보관한다. 질문·가설·변인·해석은 학생이 직접 쓴다. HTML 보고서와 기록 JSON, 조건 JSON, 결과 CSV, 회로 공유 링크를 지원한다. 공유 링크에는 노트·실측 비교 기록 등 개인 기록을 넣지 않는다. 서버·DB·로그인·외부 예측 API는 없다. 실제 공개 자료는 저장소에 포함하므로 API 가용성과 무관하게 실행한다.

## 발화 재생

실험 실행 시 기록된 발화 시점에 뉴런을 밝히고, 출발부터 실제 계산 격자의 도착 시점까지 연결선을 따라 신호를 이동시킵니다. 막전위·주입전류 그래프의 커서도 같은 모델 시간을 표시합니다. 뉴런 안의 숫자는 해당 시점의 막전위이며 입력 사건 뉴런에는 IN/발화를 표시합니다. 빛의 지속 시간은 관찰용으로 늘렸으며 활동전위의 폭이나 크기를 계산한 값이 아닙니다.

재생·일시정지·다시 재생·다음 발화/도착 사건·시간 이동·속도·발화 주변 구간·반복을 지원합니다. 일반 회로는 0.01×, 실제 기록 비교는 0.1×로 시작합니다. 실제 기록 비교는 서로 연결된 뉴런처럼 그리지 않고 두 독립 반응을 나란히 표시합니다. 청각 회로는 선택한 방향에서 집계 실험과 같은 시드를 쓰는 첫 시행을 재생하고 220회 집계 결과와 구별해 표시합니다.

실행 버튼으로 자동 재생하며, 초기 진입에서는 대기합니다. 움직임 감소 설정에서는 자동 재생과 기본 반복을 끄고 수동 관찰을 지원합니다. 탭 전환·페이지 숨김 시 일시정지하고 조건 변경 시 이전 재생을 비활성화합니다. 보고서는 재생 커서가 없는 정적 결과를 저장합니다. 재생 기능은 발화나 수치 계산을 추가·변경하지 않습니다.

## 계산 모델

시간 ms / 전압 mV / 전류 pA / 전기용량 pF / 전도도 nS. 일반 회로는 C=200 pF, τm=20 ms, gL=C/τm=10 nS, 휴지/재설정 −65 mV, 역치 −55 mV, 불응기 2 ms. 연결은 입력 사건 이후 지연만큼 뒤에 최대 전류가 더해지고 5 ms 시정수로 감소한다. 흥분성/억제성의 부호는 시냅스 전 뉴런의 종류에서 결정한다.

`C dV/dt = -gL(V-EL) + Isyn - w`. 적응 모형에서 발화마다 w에 b를 더하고 τw로 지수 감소한다. 기본 LIF는 w=0. 회로의 막전위는 지수 감소하는 입력과 수동막 사이의 정확한 구간 해로 갱신한다. 역치 판정과 사건 도착은 계산 간격에 양자화되므로 시점 오차가 있다. 기본 dt=0.1 ms, 청각 dt=0.025 ms. 실제 기록은 비균일 timeMS를 사용하고 최대 0.05 ms 구간으로 세분하여 실제 주입 전류를 적용한다.

LIF는 활동전위 모양을 계산하지 않는다. 그래프는 역치 아래 전압과 발화 사건을 구분하며 발화 사건을 임의의 생물학적 spike 높이로 그리지 않는다. 발화 지표는 자극 구간 [시작, 끝)에서 계산한다. 초반·후반 ISI는 첫/마지막 최대 3개 간격의 평균이며, 간격이 6개 미만이면 두 묶음이 겹치지 않도록 개수를 줄인다. 간격이 2개 미만이면 비교하지 않는다. 원자료 JSON의 보조 metrics는 첫/마지막 최대 3개 간격을 사용하며 UI에서는 원본 spikeTimesMS로 재계산한다.

기본 실제 비교 조건은 휴지막전위를 보정용 기록의 초기 전압으로 맞추며 τm=40 ms, C=100 pF, 역치 −50 mV, b=10 pA, τw=150 ms이다. 이는 학생이 조절하기 위한 시작값이며 해당 세포의 추정된 생리 매개변수라고 주장하지 않는다. 모델을 고정하면 해당 세포/보정 sweep/매개변수를 함께 기록한다. 검증 자극으로 옮길 때 매개변수를 자동 보정하지 않는다.

## 청각 유효 회로

점 센서 두 개와 두 동시도착 검출 채널을 사용한다. 왼쪽 음원은 왼쪽 사건을 먼저 발생시키고, 왼쪽 검출기에는 왼쪽 1.45 ms/오른쪽 1 ms 지연을 둔다. 오른쪽은 반대로 연결한다. 외부 도착 차이는 간격/343×sin(각도)이며 주파수·회절·머리 구조는 계산하지 않는다. 입력 센서 간격을 실제 두 귀의 음향학적 모형과 동일하게 해석하지 않는다.

검출기 조건: C=50 pF, τm=2 ms, 역치 −60.4 mV, 시냅스 전류 시정수 0.5 ms. 입력과 같은 쪽의 억제성 사건은 반대 검출기로 간다. 이 세포/연결은 계산을 위한 유효 단위이며 실제 청각 뉴런형·해부학을 재구성한 모델이 아니다. 종/영역이 다른 Allen 피질 자료를 이 회로의 검증 근거로 쓰지 않는다. 고정된 회로를 조절하고 미리 정한 방향 집합에서 검사하는 탐색 활동이며 별도 자료로 검증된 모델 성능이 아니다.

## 보호·재현성

가져오기와 공유 링크는 JSON 스키마·배열 크기·ID·연결 대상·숫자 범위를 검증한다. 사용자 문자열은 HTML 이스케이프한다. 보고서에 들어가는 저장 그래프도 태그/속성 허용 목록으로 정리한다. 조건 파일은 코드로 실행하지 않는다. 난수는 Mulberry32와 Box–Muller를 사용해 입력 시점의 흔들림을 재현한다. 매개변수 지도는 조건마다 같은 시드 묶음을 사용한다. 청각 실험은 방향별로 별도 시드 묶음을 사용하며 원래 시드를 CSV/기록에 남긴다.

계산 작업은 전용 Web Worker에서 수행하고 45초를 초과하면 중단한다. 파일 불러오기는 100 KB, 공유 링크는 30,000문자까지. 기기 저장이 막히면 안내하고 다운로드를 계속 지원한다. 페이지는 키보드 탭 탐색·탭 화살표 이동·실시간 상태 알림·접근 가능한 표를 제공한다. 데이터 표와 큰 그래프는 좁은 화면에서 가로로 탐색할 수 있다.
