# 사람의 발생과 세포 분화

- 공개 활동: https://ahntibody87.github.io/advanced-life-science/gene-expression/embryo-atlas/
- 소속: 고급 생명과학 → 03 유전자의 구조와 발현
- 소스: `content/advanced-life-science/gene-expression/embryo-atlas.html`
- 동작·스타일·카드 그림: `assets/activities/embryo-atlas/`
- 배포: 이 저장소의 GitHub Pages (main / root). 외부 호스팅에 의존하지 않음.

공통 ATLL 헤더, 경로 탐색, 단원 메뉴, 활동 제목, 과목 입장 화면, 돌아가기 링크를 생성기로 유지한다. 기존 작업 공간의 Pretendard 글꼴·파란색 조작 버튼·검은색 선택 탭·회색 테두리를 사용하며, 배엽과 세포의 과학적 색상은 보존한다. 활동 CSS와 DOM 조회는 `.embryo-lab` 안으로 한정한다.

수정란부터 사람의 낭배 형성, 배엽별 대표 조직, 차등 유전자 발현, MyoD의 골격근 분화 조절을 다룬다. 미오제닌 등의 세부 이름은 생략한다. 시간·모양·이동·발현량은 교육용 개념 모형이며 실제 측정 데이터가 아니다.

## 3차원 모형

`model3d.mjs`는 Three.js 0.180.0의 WebGL 렌더러를 사용한다. 라이브러리와 MIT 라이선스를 `vendor/`에 포함하여 수업 중 외부 CDN에 접속할 필요가 없다. 별도 빌드 도구나 서버가 필요하지 않다.

- 초기 난할: 세포 중심의 3차원 위치와 크기를 연속적으로 변화시키며 분열을 표시한다. 상실배는 내부 세포를 포함한 32개의 조밀한 세포 부피로 표현한다.
- 포배낭: 닫힌 다면 세포층의 안·밖 표면, 포배강, 벽에 붙은 내세포덩어리를 표현한다. 내부 관찰은 실제 메시의 절개 평면으로 처리한다. 상실배의 잘린 면도 동일 메시의 삼각형 교차점으로 채운다.
- 낭배 형성: 원반 위 세포가 원시선 부근으로 모여 아래로 들어가고 내배엽, 중배엽이 퍼진다. 배엽 두께와 이동 통로는 관찰을 위해 과장했다.
- 접힘: 같은 좌표 함수로 입체 표면과 가로 단면을 만든다. 외배엽의 표피 부분과 신경판 부분을 별도로 변형해 신경관과 장관을 구분한다. 주변 배외 구조와 복잡한 장기 분지는 생략했다.
- 배엽에서 기관으로: `lineage3d.mjs`의 별도 확대 모형에서 외배엽의 신경판·신경관, 몸통 축옆중배엽의 체절·골격근, 내배엽의 장관·상피 경로를 각각 추적한다. 작은 전체 배아는 관찰 위치를 알려 준다. 네 단계 버튼·진행 막대·회전으로 비교하며, 중배엽 경로만 MyoD 심화 관찰로 연결한다.
- 하나의 기관과 여러 배엽: 장벽의 입체 절개 모형에서 내배엽 유래 상피와 중배엽 유래 평활근을 번갈아 강조한다. 장 신경계의 신경능선 참여와 대표 층만 표시한 한계를 설명한다.
- 골격근 분화: 같은 조명·카메라·회전·안내선을 사용하는 입체 세포 절개 모형에서 MyoD 유전자, mRNA, 리보솜, MyoD 단백질, 관련 유전자 발현, 근아세포 융합과 다핵 근관·근섬유로 이어진다. 최종 단계 끝에서만 수축을 관찰할 수 있다. 세포 비교 카드·임의 발현량 막대·ATGC 장식 문자열은 제거했다.

드래그 또는 방향키로 회전하며 기본·위·옆 시점, 확대·축소, 절개 깊이, 겉층 불투명도를 조절한다. WebGL이 없거나 연결이 끊기면 안내를 표시한다. 동작은 사용자 재생으로 시작한다.

이는 실제 배아의 영상 재구성, 개별 세포 계보 추적, 힘을 계산하는 발생 시뮬레이션이 아니다. 실제 발생에서 겹쳐 일어나는 과정을 학습 순서로 나누었다. 포배낭 바깥 세포층을 외배엽으로 연결하지 않으며, 기관 전체가 하나의 배엽에서 유래한다고 설명하지 않는다.

참고: [UNSW 낭배 형성](https://embryology.med.unsw.edu.au/embryology/index.php/Gastrulation), [University of Cincinnati 배아 접힘](https://med.uc.edu/landing-pages/embryonic-folding/longitudinal-section).

표지 `preview.webp`는 기존 생물학 삽화와 맞춘 새로운 교육용 개념 삽화다. 내장 이미지 생성 도구로 생성했으며 실제 배아 사진이 아니다. PNG 원본과 생성 설명은 작업 공간의 `outputs/human-development/`에 보관한다. 기존 공개 URL은 링크 호환성을 위해 유지한다.

수정 시 이 저장소의 활동 소스를 편집하고, CSS/JS 참조의 캐시 버전을 갱신한 후 `node scripts/build.mjs`와 `node scripts/check.mjs`를 실행한다.

## 2026-10-28 개편과 입장 유지

- 내용·단계 설명은 `lineage-data.mjs`, 확대 모형은 `lineage3d.mjs`, 조작은 `lab.mjs`에서 관리한다. 01의 발생 모형과 배속은 유지한다. 확대 모형은 탭을 처음 열 때 생성하고 사용자 조작 시에만 장면을 갱신한다.
- 신경관의 길이 방향 닫힘, 장관과 난황낭의 연결, 근육 세포의 실제 이동은 단순화했다. 후기 장 상피의 융모는 시간과 배율을 건너뛴 예시임을 명시한다. 외배엽·중배엽·내배엽 모두 상배엽에서 유래한다는 01의 설명과 충돌하지 않는다.
- 공통 입장 화면에 기본 미선택인 ‘이 브라우저에서 30일간 입장 유지’를 추가한다. 비밀번호는 저장하지 않고 기존 입장 확인값과 만료 시각을 브라우저에 보관한다. 잘못된 값·만료·다른 과목·비밀번호 변경은 재입장을 요구한다. 저장 제한 시 현재 탭 입장으로 내려가며, 본문 하단 ‘입장 기억 지우기’는 해당 과목의 기억과 현재 탭 입장을 지운다.
- 이는 기존 공개 정적 사이트의 클라이언트 입장 화면이며 서버 인증이나 비공개 자료 보호 기능으로 설명하지 않는다. DB·별도 호스팅·학생 데이터 수집은 추가하지 않는다.
- 개편 전 복원 기준 커밋: `0dacd2dcc92021a362145c3db5d57729cdcf3c31`. 변경 이력에서 이 개편 커밋을 정상 revert하고 Pages로 재배포할 수 있다. 강제 push나 기록 초기화는 사용하지 않는다.
- 검사: `node scripts/check.mjs`, `node scripts/check-course-access.mjs`, 실제 브라우저에서 세 배엽의 각 네 단계·MyoD 다섯 단계·회전·연결·수축·새 탭 입장·기억 삭제·좁은 화면과 공통 배너를 확인한다.

안내선은 실제 메시의 정점과 세포 인스턴스 좌표에 연결하여 난할·원반 확대·접힘·회전·확대에 따라 갱신한다. 절개로 없어진 지점은 같은 조직의 남은 표면으로 옮기며, 전체가 제거된 구조의 명칭과 선은 숨긴다. 다른 층에 가려진 배엽은 보이는 가장자리를 우선 표시하고, 가려진 내부 부위는 점선과 빈 원으로 구분한다. 3D 캔버스와 안내선은 동일한 표시 영역을 사용하며 좁은 화면에서는 카메라 거리를 자동 조절한다.

초기 난할의 세포는 반투명하게 표시하고 핵은 상실배와 같은 회청색의 단순한 구로 표현한다. DNA 장식 선은 사용하지 않는다. 핵과 내세포덩어리 안내선은 구 표면의 최근접 정점을 탐색하지 않고 해당 핵 또는 세포 인스턴스의 로컬 중심 좌표를 추적하여 흔들림을 방지한다. 기본 1배속은 이전보다 20% 빠르며, 속도 선택은 0.5×·1×·1.5×·2×를 제공한다. 각 배속은 변경된 기본 속도를 기준으로 한다.
