# Ahntibody’s Advanced Lifescience Lab

고급생명과학 수업용 GitHub Pages 홈페이지입니다.

- 홈페이지: https://ahntibody87.github.io/
- 공개 저장소: https://github.com/ahntibody87/ahntibody87.github.io
- 게시 방식: main 브랜치 루트의 정적 파일을 GitHub Pages에서 게시
- 별도 설치·로그인·Vercel·Supabase 없이 작동합니다.

## 수정과 운영

- `index.html`: 수업 소개, 탐구·실험, 수업 자료, 이용 안내
- `assets/style.css`: PC·모바일 화면 디자인
- `assets/app.js`: 모바일 메뉴
- 자료를 추가할 때는 `index.html`의 해당 목록을 수정하고 공개가 승인된 파일만 추가합니다.
- main 브랜치에 변경을 저장하면 GitHub Pages가 자동으로 게시합니다. GitHub의 Actions 또는 Settings → Pages에서 게시 상태를 확인할 수 있습니다.
- 이전 실험·수업 자료는 포함하지 않았습니다. 현재 자료와 활동 목록은 비어 있습니다.
- 이 저장소의 파일은 인터넷에 공개됩니다. 정답·교사용 초안·학생 기록·비밀번호·인증 정보는 넣지 않습니다.

기존 별도 웹앱과 데이터는 변경하거나 삭제하지 않았습니다.
