# Activity preview sources

- `mitochondria-lab.svg`: schematic respiration plot from the approved design mockup; not measured patient data. The card labels it as a conceptual diagram.
- `protein-lab.svg`: Cα trace derived from chain A of ubiquitin, [RCSB PDB 1UBQ](https://www.rcsb.org/structure/1UBQ). The card labels it as an example structure, not a prediction result. No model weights are included.
- `bbb-lab.png`, `neuron-lab.png`, `rna-lab.png`, `x-inactivation.png`: snapshots of this repository's existing interactive observation panels, taken locally in their initial states. They contain no student records or personal information.

Update a preview when its observation panel changes. Activities are listed from `data/site.json`; these files do not register new activities.
