# Platform Overview visual sources

The figures are generated as SVG from data or an explicitly labelled educational model. The embedded protein cartoon and RNA ball-and-stick posters (`protein-overlay.webp`, `rna-fold.webp`) were rendered from the preserved coordinates using the existing bundled 3Dmol 2.5.5 renderer; the mutant is rigidly aligned to the reference before rendering. Only chain A residues 1–162 are displayed for each protein. Cyan is the reference and gold is the variant; residue 99 is highlighted. The two models use the same camera. No image-generation model is used for these scientific figures. Visitors load the finished illustrations, not prediction model weights.

- `protein-comparison.svg`: Cα alignment of chain A residues 1–162 from [4S0W, wild-type T4 lysozyme](https://www.rcsb.org/structure/4S0W) and [7LX7, L99A T4 lysozyme](https://www.rcsb.org/structure/7LX7). The only sequence difference among aligned residues is L99A. Both are experimental structures, from different crystal conditions. Their differences do not isolate a mutation effect or establish a functional change. Coordinates are preserved in `t4-reference.pdb` and `t4-l99a.pdb`. The existing `protein-lab/core.js` performs the rigid alignment. The figure is explicitly a reference comparison, not an ATLL prediction.
- `rna-design.svg`: secondary structure `((((....))))` of `GGGGAAAACCCC`, including the activity’s ribose–phosphate backbone and base ring geometry (`molecule.js` layout), and actual all-atom output from ATLL's shipped RNAbpFlow CASP16 engine (50 steps, seed 420). The target structure is an input condition, not an independently validated fold. `rna-hairpin.pdb` and `rna-hairpin.json` preserve the output and settings. Structure prediction does not establish ribozyme activity. Attribution: Sumit Tarafder and Debswapna Bhattacharya, [RNAbpFlow](https://github.com/Bhattacharya-Lab/RNAbpFlow), model weights CC BY 4.0. Upstream source, notices, model provenance and licences remain in `assets/activities/rna-lab/vendor/rnabpflow/`.
- `bbb-simulation.svg`: `simulate(defaults, false/true)` from the existing `assets/activities/bbb-lab/model.mjs`. Each series has 121 time points; y is active drug currently in the brain compartment as a percentage of initial amount. The horizontal coordinate is dimensionless model progression. It is not clinical data, real time, cumulative entry or a validated delivery rate. The upper moving particles are a schematic illustration, not individual simulated molecules.
- `inquiry-evidence.svg`: three categorical qualitative treatment patterns from `assets/activities/cell-energy/model.mjs` (A cyanide, B DNP, C oligomycin), for oxygen consumption, oxidative ATP synthesis and proton electrochemical gradient. The display is about relative direction, not numeric effect sizes or measured patient data.

The four `*-mobile.svg` variants use the same coordinates and data, with stacked panels and larger labels for narrow screens.

Regenerate the four figures, their mobile variants and provenance using `node scripts/generate-overview.mjs`, then run `node scripts/build.mjs`, `node scripts/check.mjs` and `node scripts/check-overview.mjs`. The RNA prediction is a prepared asset; page rendering and figure regeneration do not run or download the neural model.
