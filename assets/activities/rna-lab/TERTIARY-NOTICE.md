# RNA 3차 구조 예측

계산은 사용자의 브라우저 Web Worker와 WebGPU에서 실행합니다. 입력 서열을 외부 계산 서버로 전송하지 않습니다. 모델 파일을 받으려면 첫 실행 시 인터넷 연결이 필요합니다. 브라우저 캐시는 저장 공간 부족 등에 따라 지워질 수 있습니다.

## 설정과 표시

표준 A·U·G·C로 이루어진 단일 가닥 8~120 nt를 받습니다. 단일 서열, MSA 없음, 구조 주형 없음, diffusion 200 steps, recycle 설정 1, seed 0·1·2로 세 후보를 계산합니다. 같은 서열의 trunk/target features를 재사용하고 확산의 시작 조건을 바꿉니다. 기본 구조 검사를 통과한 후보 중 이상 점수가 낮은 후보를 선택합니다. 신뢰도 색상은 모델이 제공한 보정 전 원자별 pLDDT이며 실제 정답 확률이 아닙니다. 기기에 따라 GPU 지원, 속도와 메모리 한계가 다릅니다. 계산 중단 시 Worker를 종료합니다.

3D 결합선은 wwPDB Chemical Component Dictionary의 표준 A/C/G/U 공유결합과 이웃 O3′–P 연결로 정합니다. 거리만으로 결합을 추가하지 않으며, 심하게 비정상적인 길이의 선은 생략합니다. 당은 청회색, 인산은 주황, 염기는 종류별 색으로 표시합니다. 연결 산소 O3′·O5′는 당 색으로 묶습니다. 막대는 공유결합을 보여주며 결합 차수를 구별하지 않습니다.

골격·당 고리·당–염기 연결·염기 고리·인산의 결합 길이, 결합각, 당 입체배치, 염기 평면, 비공유 원자 충돌을 검사합니다. 심한 이상이 있으면 제외합니다. 작은 이상에 한해 원자당 약 0.3 Å 이내의 기하 보정을 시도하고, 구조 이상과 충돌이 악화되지 않을 때만 채택합니다. 분자동역학이나 실제 접힘 경로가 아닙니다. 원본 좌표와 보정 기록을 결과 JSON에 보존합니다. 세 후보가 모두 미통과하면 기본 3D 결과를 표시하지 않습니다. 예전 JSON을 직접 열면 다시 검사하고 미통과 경고와 함께 참고용으로 표시할 수 있습니다.

2D 비교의 아래쪽 곡선은 3D 좌표에서 다음 조건으로 찾은 **기하학적 염기쌍 후보**입니다. FR3D 또는 DSSR의 정밀 주석이 아니며, 비정형 결합과 여러 대안은 다루지 않습니다.

- A–U: N6–O4, N1–N3; G–C: O6–N4, N1–N3, N2–O2; G–U: O6–N3, N1–O2.
- 각 거리 2.3~3.8 Å, C1′ 간 거리 8~13 Å, 평면 법선 차이 30° 이내, 상대 평면으로부터 거리 1.5 Å 이내, 서열상 4자리 이상 떨어진 염기.
- 겹치는 후보는 접촉 거리의 2.9 Å로부터의 평균 편차가 작은 것부터 선택하며 한 염기당 한 짝만 표시합니다. 교차하는 쌍도 곡선으로 표시할 수 있습니다.
- 구조 검사 기준은 [개선·검증 문서](/docs/rna-quality-improvements.md)에 기록합니다. 앱의 기본 검사이며 FR3D/DSSR/MolProbity나 전체 구조 정확성 검증을 대신하지 않습니다.

임의 서열의 실제 구조·안정성·생물학적 기능은 실험으로 확인해야 합니다. 2차·3차 예측의 일치가 정확성을 증명하지 않습니다. 최근 5개의 서열과 결과를 이 브라우저에 보관하며, 저장한 JSON을 다른 기기에서 열 수 있습니다. 파일의 모델 출처는 작성자 기록으로 표시합니다.
